# calculator

Консольный калькулятор. Последовательно выполняет операции над текущим результатом, пока пользователь не выйдет.

[Назад к общему README](../README.md)

## Возможности

- Операции: `+`, `-`, `*`, `/`
- Цепочка вычислений: результат предыдущей операции становится первым операндом следующей
- Дробные числа можно вводить и через точку, и через запятую (`2.5` и `2,5`)
- `C` - сброс результата в 0
- `S` - выход из программы
- Обработка ошибок: нечисловой ввод, неизвестная операция, деление на ноль

## Запуск

Через Gradle:

```bash
./gradlew :calculator:run -q --console=plain
```

Флаги `-q --console=plain` убирают служебный вывод Gradle, чтобы он не мешал вводу.

Через jar:

```bash
./gradlew :calculator:build
java -jar calculator/build/libs/calculator-1.0.jar
```

Из IntelliJ IDEA: открыть `calculator/src/main/java/Calculator.java` и запустить метод `main`.

## Пример работы

```
Калькулятор
Операции: +, -, *, /
C - сброс, S - выход

Введите число: 10
Введите операцию (+, -, *, /): *
Введите второе число: 2,5
Результат: 25
Введите операцию (+, -, *, /): /
Введите второе число: 0
Ошибка: деление на ноль. Результат: 25
Введите операцию (+, -, *, /): c
Результат сброшен: 0
Введите число: s
Калькулятор выключен
```
