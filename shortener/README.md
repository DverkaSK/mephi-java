# shortener

Консольный сервис сокращения ссылок с лимитом переходов, ограниченным временем жизни и управлением ссылками по UUID пользователя.

[Назад к общему README](../README.md)

## Возможности

| Требование ТЗ | Как реализовано |
|---|---|
| Сокращение длинных URL | `shorten <url>` возвращает ссылку вида `clck.ru/aB3xYz` |
| Уникальные ссылки для разных пользователей | Каждое сокращение получает новый случайный код base62, занятость кода проверяется в хранилище, поэтому один и тот же URL у разных пользователей (и даже у одного) дает разные ссылки |
| Лимит переходов | Задается при создании (`shorten <url> 5`) или берется из конфигурации; после исчерпания переход блокируется |
| Время жизни | Задается только конфигурацией (`link.ttl`), пользователь изменить его не может; просроченные ссылки удаляются фоновой задачей и при любом обращении к ним |
| Уведомления | Владелец получает уведомление об исчерпании лимита и об удалении по сроку; тот, кто переходит по недоступной ссылке, видит причину и подсказку, как создать новую |
| Идентификация по UUID | UUID выдается при первом сокращении, по нему можно вернуться к своим ссылкам (`login <UUID>`) после перезапуска |
| Права владельца | Просмотр, изменение лимита и адреса, удаление доступны только создателю ссылки |
| Переход из консоли | Достаточно вставить короткую ссылку, исходный адрес откроется в браузере через `Desktop.browse` |
| Конфигурация | Все параметры читаются из `application.properties`, их можно переопределить своим файлом или `-D` параметрами |

## Требования и установка

- JDK 21
- Gradle устанавливать не нужно, используется Gradle Wrapper из корня репозитория

Внешняя зависимость одна: Jackson Databind (сохранение ссылок в JSON). Она скачивается Gradle автоматически из Maven Central, отдельно ставить ничего не нужно.

## Запуск

Из корня репозитория:

```bash
./gradlew :shortener:installDist
shortener/build/install/shortener/bin/shortener
```

На Windows:

```powershell
gradlew.bat :shortener:installDist
shortener\build\install\shortener\bin\shortener.bat
```

Через Gradle (удобно для быстрой проверки, флаги убирают служебный вывод Gradle):

```bash
./gradlew :shortener:run -q --console=plain
```

Из IntelliJ IDEA: запустить `ru.mephi.shortener.ShortenerApp`.

## Команды

| Команда | Синонимы | Что делает |
|---|---|---|
| `help [команда]` | `?`, `h` | Список команд или справка по одной команде с примерами |
| `shorten <url> [лимит]` | `s`, `create` | Сократить ссылку. Без лимита используется значение из конфигурации. Схему можно не указывать: `github.com` станет `https://github.com` |
| `<короткая ссылка>` | | Просто вставленная ссылка `clck.ru/aB3xYz` открывается в браузере |
| `open <ссылка>` | `go` | То же, что вставить ссылку. Принимает и код, и ссылку целиком |
| `list` | `ls` | Ваши ссылки: переходы, статус, срок действия, исходный адрес |
| `info <ссылка>` | | Подробности по одной своей ссылке |
| `limit <ссылка> <лимит>` | | Изменить лимит переходов. Новый лимит должен быть больше уже совершенных переходов. Увеличение лимита разблокирует исчерпанную ссылку |
| `edit <ссылка> <новый url>` | | Изменить адрес, на который ведет ссылка, код сохраняется |
| `delete <ссылка>` | `rm` | Удалить свою ссылку |
| `whoami` | | Показать текущий UUID |
| `login <UUID>` | | Переключиться на пользователя по UUID |
| `logout` | | Выйти; следующее сокращение создаст нового пользователя |
| `exit` | `quit`, `q` | Выйти из программы, напомнив UUID |

Вместо `<ссылка>` подходят `aB3xYz`, `clck.ru/aB3xYz` и `https://clck.ru/aB3xYz`.

## Конфигурация

Значения по умолчанию лежат в [`src/main/resources/application.properties`](src/main/resources/application.properties):

| Параметр | По умолчанию | Описание |
|---|---|---|
| `link.domain` | `clck.ru` | Домен коротких ссылок |
| `link.code-length` | `6` | Длина кода (от 4 до 16 символов) |
| `link.ttl` | `24h` | Время жизни ссылки |
| `link.click-limit.default` | `10` | Лимит переходов, если пользователь его не указал |
| `link.click-limit.max` | `100000` | Максимально допустимый лимит |
| `link.url.max-length` | `2048` | Максимальная длина исходного URL |
| `cleanup.interval` | `30s` | Как часто фоновая задача удаляет просроченные ссылки |
| `storage.file` | `~/.shortener/links.json` | Файл, где хранятся ссылки между запусками. Пустое значение: хранить только в памяти |

Длительности записываются как `30s`, `15m`, `24h`, `1d` или в формате ISO-8601 (`PT1H30M`).

Переопределение, в порядке возрастания приоритета:

1. Свой файл: `shortener --config my.properties` (или `-Dshortener.config=my.properties`). В нем достаточно указать только изменяемые параметры.
2. Системные свойства JVM: `JAVA_OPTS="-Dlink.ttl=1h -Dlink.click-limit.default=3" shortener`.

Некорректная конфигурация (например, `link.ttl=0s` или `link.click-limit.max` меньше значения по умолчанию) обнаруживается при запуске, программа выводит понятное сообщение и завершается с кодом `2`.

## Архитектура

```
ru.mephi.shortener
├── ShortenerApp            точка входа и сборка зависимостей (composition root)
├── domain                  ядро: ShortLink, LinkStatus, Notification, исключения предметной области
├── service                 бизнес-логика: LinkService, LinkPolicy, UrlValidator, ShortLinkFormat,
│   │                       RandomCodeGenerator, ExpirationScheduler
│   └── port                интерфейсы, которые ядро требует от инфраструктуры:
│                           LinkRepository, ShortCodeGenerator, NotificationService, NotificationInbox
├── infra                   реализации портов
│   ├── storage             InMemoryLinkRepository, FileLinkRepository (JSON, атомарная запись)
│   ├── notification        InMemoryNotificationInbox
│   └── browser             DesktopBrowserLauncher
├── config                  AppConfig, ConfigLoader, DurationParser
└── cli                     консольный интерфейс: ShortenerCli, Session, LinkView, CommandRegistry
    └── command             по классу на команду (ShortenCommand, OpenCommand, LimitCommand, ...)
```

Зависимости направлены внутрь: `cli` и `infra` зависят от `service` и `domain`, ядро не знает ни о консоли, ни о файлах, ни о `java.awt`. Все зависимости передаются через конструкторы, время берется из инжектируемого `java.time.Clock`, поэтому TTL проверяется в тестах без ожидания.

### Принятые решения

- **Алгоритм сокращения.** Код из `link.code-length` символов алфавита `[0-9A-Za-z]` генерируется `SecureRandom`. При шести символах это 62^6, около 5.7 * 10^10 вариантов. Перед сохранением код проверяется на занятость, при коллизии генерируется новый (до 20 попыток). Код глобально уникален, поэтому ссылки разных пользователей никогда не совпадают, а угадать чужую ссылку перебором практически невозможно.
- **Лимит переходов.** Переход засчитывается атомарно (методы `LinkService` синхронизированы), поэтому при параллельных обращениях счетчик точный. Ссылка с лимитом `N` открывается ровно `N` раз; на `N`-м переходе владелец получает уведомление, следующие попытки блокируются. Исчерпанная ссылка не удаляется сразу, чтобы владелец мог увеличить лимит, но удаляется по истечении срока.
- **Время жизни.** Срок задается только конфигурацией. Удаление гарантируется двумя механизмами: фоновая задача `ExpirationScheduler` раз в `cleanup.interval` удаляет все просроченные ссылки (первый проход сразу при запуске), а любое обращение к ссылке проверяет срок и удаляет ее на месте. Поэтому просроченная ссылка не откроется даже в промежутке между проходами фоновой задачи.
- **Уведомления.** Ядро публикует события `LIMIT_EXHAUSTED` и `EXPIRED` в `NotificationService`. Консоль показывает накопленные уведомления текущего пользователя перед каждым приглашением ко вводу, в том числе сразу после `login`.
- **Права доступа.** Каждая операция изменения принимает UUID текущего пользователя, и `LinkService` сверяет его с владельцем до любых изменений. Обойти проверку из консоли нельзя: другой пользователь получает `AccessDeniedException`.
- **Хранение.** Ссылки сохраняются в JSON после каждого изменения через временный файл и атомарное переименование, поэтому файл не портится при аварийном завершении. Хранилище скрыто за интерфейсом `LinkRepository` и заменяется без изменения логики.
- **Валидация.** URL нормализуется (добавляется `https://`, если схема не указана) и проверяется: только `http`/`https`, есть домен, корректный порт, ограничение длины, запрет повторно сокращать собственные короткие ссылки. Ошибки ввода показываются понятным текстом, программа не падает; непредвиденное исключение в команде выводится, но цикл продолжается.

## Тестирование

```bash
./gradlew :shortener:test
```

Отчет: `shortener/build/reports/tests/test/index.html`. Сеть, браузер и запись в домашний каталог тестам не нужны: время подменяется через `MutableClock`, браузер заменяется заглушкой, файловые тесты работают во временном каталоге.

| Класс | Что проверяет |
|---|---|
| `ShortenerScenarioTest` | Интеграционные сценарии через консольный интерфейс: первый запуск и выдача UUID, переход по вставленной ссылке, разные ссылки у разных пользователей, исчерпание лимита с уведомлением и разблокировкой, удаление по сроку с уведомлением, запрет управлять чужой ссылкой, сообщения об ошибках ввода, help и exit |
| `LinkServiceTest` | Уникальность кодов (в том числе 2000 ссылок при коротком коде), повтор при коллизии, несколько ссылок у пользователя и изоляция пользователей, точная блокировка по лимиту, точный подсчет при 300 параллельных переходах, истечение срока при TTL 1 час, 24 часа и 7 дней ровно в момент окончания, фоновая очистка, права владельца, валидация лимитов, изменение адреса |
| `ExpirationSchedulerTest` | Фоновое удаление просроченных ссылок без обращения к ним, устойчивость задачи к ошибкам |
| `UrlValidatorTest` | Нормализация и отклонение некорректных URL, ограничение длины |
| `ShortLinkFormatTest` | Разбор кода из `aB3xYz`, `clck.ru/aB3xYz`, `https://clck.ru/aB3xYz` |
| `ConfigLoaderTest` | Значения по умолчанию, приоритет своего файла и `-D` параметров, форматы длительностей, отклонение некорректных значений |
| `FileLinkRepositoryTest` | Сохранение между запусками, обработка поврежденного файла |
| `ShortLinkTest`, `RandomCodeGeneratorTest`, `InMemoryNotificationInboxTest`, `ShortenerAppTest` | Модель, генератор кодов, доставка уведомлений, разбор аргументов запуска |

Проверка вручную: запустить с коротким сроком жизни и посмотреть, как ссылка удаляется сама:

```bash
JAVA_OPTS="-Dlink.ttl=1m -Dcleanup.interval=5s -Dstorage.file=" shortener/build/install/shortener/bin/shortener
```

Создайте ссылку, подождите минуту и нажмите Enter: появится уведомление об удалении, `list` покажет пустой список.

## Коды завершения

| Код | Причина |
|---|---|
| `0` | Нормальное завершение |
| `1` | Ошибка чтения файла хранилища или ввода |
| `2` | Некорректная конфигурация или аргументы запуска |
