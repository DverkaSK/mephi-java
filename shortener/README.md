# shortener

Консольный сервис сокращения ссылок с лимитом переходов и сроком жизни. Пользователь определяется по UUID, который выдается при первом сокращении. Изменять и удалять ссылку может только ее владелец.

[Назад к общему README](../README.md)

## Запуск

Нужна JDK 21. Зависимость одна, Jackson, Gradle скачивает ее сам.

```bash
./gradlew :shortener:installDist
shortener/build/install/shortener/bin/shortener
```

На Windows: `gradlew.bat :shortener:installDist`, затем `shortener\build\install\shortener\bin\shortener.bat`.

## Команды

```
help [команда]              список команд или справка по команде
shorten <url> [лимит]       сократить ссылку
open <ссылка>               перейти по ссылке (или просто вставить ссылку)
list                        мои ссылки
info <ссылка>               информация о ссылке
limit <ссылка> <лимит>      изменить лимит переходов
edit <ссылка> <новый url>   изменить адрес
delete <ссылка>             удалить ссылку
whoami                      показать UUID
login <UUID>                войти по UUID
logout                      выйти
exit                        выйти из программы
```

## Настройки

`src/main/resources/application.properties`:

```properties
link.domain=clck.ru
link.code-length=6
link.ttl=24h
link.click-limit.default=10
link.click-limit.max=100000
link.url.max-length=2048
cleanup.interval=30s
storage.file=~/.shortener/links.json
```

## Устройство

- `domain`: модель ссылки, уведомления, исключения
- `service`: логика (`LinkService`), проверка URL, генерация кодов, фоновая очистка; интерфейсы хранилища и уведомлений в `service.port`
- `infra`: хранение в памяти и в JSON, уведомления, открытие браузера
- `config`: чтение настроек
- `cli`: консоль, каждая команда в отдельном классе

Код ссылки состоит из 6 случайных символов `[0-9A-Za-z]` (`SecureRandom`). Если код уже занят, генерируется новый. Каждое сокращение получает свой код, поэтому у разных пользователей ссылки на один адрес различаются.

Просроченные ссылки удаляет фоновая задача раз в `cleanup.interval`. Кроме того, срок проверяется при каждом обращении к ссылке.

## Тесты

```bash
./gradlew :shortener:test
```

`LinkServiceTest` проверяет основную логику: уникальность ссылок, блокировку по лимиту, удаление по сроку, права владельца. `ShortenerScenarioTest` проходит те же сценарии через консоль. Остальные тесты покрывают валидацию URL, настройки, хранилище и фоновую очистку.
