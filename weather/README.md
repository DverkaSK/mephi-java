# weather

Консольный сервис получения метеорологических данных из [API Яндекс Погоды](https://yandex.ru/dev/weather/doc/ru/concepts/how-to).

[Назад к общему README](../README.md)

## Что делает

1. Выполняет `GET https://api.weather.yandex.ru/v2/forecast?lat=...&lon=...&limit=...` с заголовком `X-Yandex-Weather-Key`
2. Выводит в консоль полный JSON-ответ сервиса без изменений
3. Выводит текущую температуру из `fact.temp`
4. Считает среднее арифметическое `forecasts[*].parts.day.temp_avg` по первым `limit` суткам прогноза и выводит его

## Получение ключа API

1. Зайти в [консоль Яндекс Погоды](https://yandex.ru/pogoda/b2b/console/home) и выбрать тариф "API Яндекс.Погоды"
2. Скопировать выданный ключ

Перед использованием стоит проверить условия тарифа: срок тестового доступа, лимит запросов и максимальное число дней прогноза. Новый ключ может активироваться не сразу, до этого сервис отвечает `403 forbidden`.

Ключ не хранится в коде, приложение читает его из переменной окружения `YANDEX_WEATHER_KEY`.

## Запуск

Аргументы командной строки (все необязательные):

| Позиция | Параметр | По умолчанию | Ограничения |
|---|---|---|---|
| 1 | `lat` - широта | `55.75` | от -90 до 90 |
| 2 | `lon` - долгота | `37.62` | от -180 до 180 |
| 3 | `limit` - количество суток прогноза | `7` | целое число больше 0 |

Без аргументов используются координаты Москвы.

PowerShell:

```powershell
$env:YANDEX_WEATHER_KEY = "ваш_ключ"
./gradlew :weather:run --args="55.75 37.62 7"
```

Bash:

```bash
export YANDEX_WEATHER_KEY="ваш_ключ"
./gradlew :weather:run --args="55.75 37.62 7"
```

Через jar (зависимости лежат в дистрибутиве, поэтому используется `installDist`):

```bash
./gradlew :weather:installDist
weather/build/install/weather/bin/weather 59.94 30.31 5
```

Из IntelliJ IDEA: запустить `ru.mephi.weather.WeatherApp`, в Run Configuration в поле Environment variables указать `YANDEX_WEATHER_KEY=ваш_ключ`, в Program arguments при необходимости `55.75 37.62 7`.

## Пример вывода

```
GET https://api.weather.yandex.ru/v2/forecast?lat=55.75&lon=37.62&limit=7
Полный ответ сервиса:
{"now":1792503749,"now_dt":"2026-10-20T13:42:29.107985Z","info":{"n":true,"url":"https://yandex.ru/pogoda/?lat=55.75&lon=37.62","lat":55.75,"lon":37.62, ...}

Текущая температура (fact.temp): 8 °C
Средняя дневная температура (parts.day.temp_avg) за 7 из 7 запрошенных дн.: 10.0 °C
```

В примере JSON сокращен, программа выводит его целиком.

Если сервис вернул меньше дней, чем запрошено в `limit` (например, из-за ограничений тарифа), среднее считается по доступным дням, и это видно в выводе: `за 3 из 7 запрошенных дн.`

## Коды завершения

| Код | Причина |
|---|---|
| `0` | Успешно |
| `1` | Ошибка сервиса (HTTP не 200), сети или разбора ответа |
| `2` | Некорректные аргументы или не задан ключ API |

## Тесты

```bash
./gradlew :weather:test
```

Ключ и доступ в интернет для тестов не нужны: HTTP-запросы идут на локальный тестовый сервер. Тесты проверяют разбор аргументов, формирование URL, наличие заголовка `X-Yandex-Weather-Key` и параметра `limit` в запросе, обработку ошибочных ответов, извлечение `fact.temp` и расчет средней температуры.
